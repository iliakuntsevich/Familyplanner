# Семейный календарь Ильи и Лейлы

Сайт: GitHub Pages из ветки `main` (файл `index.html`).
Данные хранятся в Supabase (таблицы `events` и `tasks`), вход по email и паролю.
В `index.html` указан только публичный ключ (publishable/anon) — это нормально, доступ к данным защищён входом и правилами RLS.
